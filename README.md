# BIM Budget Guard 🏗️

> A lightweight AI co-builder and submission partner that analyzes early-stage Revit schedule exports to predict potential material cost overruns, missing data, and budget risks.

🚀 **[Try the Live Web App Here]https://bim-budget-guard-t7mzf6pzsstxlhkpktg8o8.streamlit.app/**

## Overview
Early-stage Building Information Models (BIM) often lack granular material data, leading to significant budget blind spots and cost overruns later in construction. **BIM Budget Guard** solves this for architects and quantity surveyors by allowing users to upload standard Revit CSV schedules, instantly parsing data through a deterministic risk dashboard and an AI Quantity Surveyor agent.

## Key Features
- **Deterministic Risk Dashboard:** Instantly flags missing materials, zero-volume geometry errors, and missing unit costs.
- **AI Agent Audit Report:** Generates an executive-level quantity surveyor risk audit and actionable recommendations.
- **Lightweight Stack:** Built with Python, Streamlit, Pandas, and Claude AI integration.
